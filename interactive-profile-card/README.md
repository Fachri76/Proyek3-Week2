# Interactive Profile Card
Project ini dibuat menggunakan HTML, CSS, dan Vanilla JavaScript.
## Cara Menjalankan
Project harus dijalankan menggunakan local development server karena data profil dimuat menggunakan fetch.
Contoh menggunakan Visual Studio Code:
1. Buka folder project di Visual Studio Code.
2. Jalankan menggunakan Live Server.
3. Buka halaman melalui alamat localhost yang diberikan.
## Fitur
- Memuat profil dari data/profile.json
- State loading, empty, success, dan error
- Tombol Coba Lagi
- Toggle detail profil
- Pergantian tema
- Penambahan keterampilan
- Validasi input kosong
- Penghapusan keterampilan
