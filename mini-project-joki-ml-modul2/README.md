# Mini Project Modul 2 - Joki Mobile Legends

Mini project ini mengembangkan landing page statis Modul 1 menjadi landing page interaktif menggunakan Vanilla JavaScript.

## Fitur

1. Navigasi mobile dapat dibuka dan ditutup.
2. Layanan dirender dari array of objects.
3. Layanan dapat difilter.
4. FAQ menggunakan accordion dan aria-expanded.
5. Form kontak memiliki validasi.
6. Tombol Kembali ke Atas muncul setelah halaman discroll.
7. Tema terang/gelap diubah melalui class CSS.

## Teknologi

- HTML5
- CSS3
- Vanilla JavaScript

Tidak menggunakan framework, library UI, fetch, Promise, atau async/await.

## Struktur Folder

- index.html
- css/style.css
- js/app.js
- evidence/

## Cara Menjalankan

Buka index.html melalui browser atau Live Server.

## Pengujian yang Disarankan

- Mobile: 320px
- Tablet: 768px
- Desktop: 1024px
- Keyboard: Tab, Enter, Space
- Console: pastikan tidak ada error pada alur normal

## Catatan

Website ini dibuat sebagai contoh project pembelajaran dan bukan layanan joki nyata.
